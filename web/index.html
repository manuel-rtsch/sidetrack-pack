Sidetrack App Pack

This host serves an F-Droid repository for Sidetrack, a music player for the Sidephone SP-01.

It is meant to be added to the SP-01's Library app, not browsed here. Open Library → Settings → App Packs → + and scan the QR code below, or add the address by hand:

https://manuel-rtsch.github.io/sidetrack-pack/fdroid/repo

The phone shows this signing fingerprint as it adds the pack. Check it against the value here. Every update is verified against it afterwards without asking, so this one check is all you have to do.
