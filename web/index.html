Sidetrack App Pack

Add this app pack to the Library on your Sidephone SP-01 to install Sidetrack, a music player built around the keypad. Nothing is installed from this page. Read it on a second device while you work on the SP-01.

  1. On the SP-01, open Library → Settings → App Packs → +.
  2. Scan the QR code below, or type the address under it.
  3. Check that the fingerprint the phone shows matches the one at the bottom of this page.

https://manuel-rtsch.github.io/sidetrack-pack/fdroid/repo

The fingerprint is the only check you need. The address and fingerprint are permanent. After you add the pack, the Library verifies every update against the fingerprint automatically.
